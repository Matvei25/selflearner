# МАРК — самообучающийся агент без нейросети 🧠

Ядро: Common Lisp (память, правила, диалог)
Генератор: Python (марковская цепь 2-го порядка)

## Запуск
```bash
./run.sh          # диалог в консоли
```

## Команды в диалоге
- `learn: вопрос => ответ` — научить агента паре
- `teach: текст` — добавить строку в корпус (учится генерить как ты)
- `markov` — сгенерировать случайную фразу
- `stats` — сколько знает пар
- `(персона имя)` — включить персонажа (Марк отвечает в его духе)
- `(персона)` — показать активную персону, `(персона -)` — снять
- `(персона-define имя характер...)` — создать/описать персонажа
- `(персона-учить текст)` — научить активную персону фразе (для генератора "по духу")
- `(правила)` — кто из правил жив, а кто умер (`☠`), у кого сколько здоровья
- `(эволюция)` — устроить суд поколения прямо сейчас
- `(воскресить имя)` — вернуть мёртвое правило к жизни
- `exit` — выход

## Как это работает (без нейросети!)
1. **Память** (`memory.lisp`) — пары «вопрос → ответ». Агент матчит твой вопрос по ключевым словам и отвечает тем, что запомнил.
2. **Корпус** (`corpus.txt`) — строки текста, на которых учится генератор.
3. **Марковская цепь** (`markov.py`) — смотрит, какие слова часто идут подряд, и генерирует похожие фразы.
4. Если агент не знает ответа — честно говорит «не знаю» и генерит фразу. Ты его учишь — он запоминает. Всё.

- [x] v0.1: память + правила + марков
- [x] v0.4: настоящий агент — цели, планировщик, журнал (`goal`/`status`/`log`/`stop`), функции на лету (`code`), лисп-синтаксис

- [x] v0.6: веб-панель — браузерный интерфейс для чата с Марком (вместо телеграма): `web/server.py` + `api-brain.lisp`, запуск `cd web && python3 server.py` → http://localhost:8000
- [x] v0.7: эволюция правил — у каждого правила (элизы и детекта инструментов) есть здоровье. Каждая услышанная реплика — тик; раз в 20 реплик суд поколения: чем никто не пользовался — теряет здоровье, на нуле умирает (перестаёт применяться), а сработавшие — жиреют. Мёртвое можно вернуть: `(воскресить имя)`. Состояние живёт в `rules.lisp`, поколение — в памяти.
- [x] v0.8: сны — ночная пересборка памяти. Раз в 25 реплик (или вручную `(dream)`) Марк «засыпает»: выбрасывает мусор (пустые ответы, `...`, вопрос-эхо), сливает похожие вопросы (схожесть по общим словам ≥ 0.75), схлопывает точные дубли — оставляя более уверенную запись. Чистит и память активной персоны.
- [x] v0.9: персонажи — `(персона имя)` (Марк становится персонажем, своя память на персону `memory_<имя>.lisp`) + генератор "по духу" (марков на корпус персоны `corpus_<имя>.txt`)
