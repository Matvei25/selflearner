# МАРК — самообучающийся агент без нейросети 🧠

Ядро: Common Lisp (память, правила, диалог)
Генератор: Python (марковская цепь 2-го порядка)

## Запуск
```bash
./run.sh          # диалог в консоли
```

## Команды в диалоге
- `learn: вопрос => ответ` — научить агента паре
- `teach: текст` — добавить строку в корпус (учится генерить как ты)
- `markov` — сгенерировать случайную фразу
- `stats` — сколько знает пар
- `exit` — выход

## Как это работает (без нейросети!)
1. **Память** (`memory.lisp`) — пары «вопрос → ответ». Агент матчит твой вопрос по ключевым словам и отвечает тем, что запомнил.
2. **Корпус** (`corpus.txt`) — строки текста, на которых учится генератор.
3. **Марковская цепь** (`markov.py`) — смотрит, какие слова часто идут подряд, и генерирует похожие фразы.
4. Если агент не знает ответа — честно говорит «не знаю» и генерит фразу. Ты его учишь — он запоминает. Всё.
