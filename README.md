# PyLiSh — самообучающийся агент без нейросети 🧠

**P**ython + **Li**sp + Ba**sh** — Марк живёт на трёх языках:

Ядро: Common Lisp (память, правила, диалог)
Генератор: Python (марковская цепь 2-го порядка)
Клей: Bash (запуск, сборка структур)

## Запуск
```bash
./run.sh          # диалог в консоли
```

## Команды в диалоге
- `learn: вопрос => ответ` — научить агента паре
- `teach: текст` — добавить строку в корпус (учится генерить как ты)
- `markov` — сгенерировать случайную фразу
- `stats` — сколько знает пар
- `(персона имя)` — включить персонажа (Марк отвечает в его духе)
- `(персона)` — показать активную персону, `(персона -)` — снять
- `(персона-define имя характер...)` — создать/описать персонажа
- `(персона-учить текст)` — научить активную персону фразе (для генератора "по духу")
- `(правила)` — кто из правил жив, а кто умер (`☠`), у кого сколько здоровья
- `(эволюция)` — устроить суд поколения прямо сейчас
- `(воскресить имя)` — вернуть мёртвое правило к жизни
- `(креативность вкл/выкл/0.2)` — вспышки креативности: температура иногда подскакивает (v1.0)
- `(дерево запрос)` — развернуть файловую структуру через mark-fs (мозг лисп + руки python) в `out/`
- `(цели)` — цели и журнал агента (читаются с диска), `(agent-clear)` — стереть их
- `exit` — выход

## Как это работает (без нейросети!)
1. **Память** (`memory.lisp`) — пары «вопрос → ответ». Агент матчит твой вопрос по ключевым словам и отвечает тем, что запомнил.
2. **Корпус** (`corpus.txt`) — строки текста, на которых учится генератор.
3. **Марковская цепь** (`markov.py`) — смотрит, какие слова часто идут подряд, и генерирует похожие фразы.
4. Если агент не знает ответа — честно говорит «не знаю» и генерит фразу. Ты его учишь — он запоминает. Всё.

## convert.py — конвертер логов в датасеты и память Марка

Превращает логи диалогов в три формата: ShareGPT, LLaMA-ChatML и **память Марка**.

```bash
python3 convert.py                          # читает tg_logs.json рядом
python3 convert.py result.json              # любой вход
python3 convert.py result.json --out dump   # префикс выходных файлов
python3 convert.py result.json --names      # "Автор: текст" (для групп)
```

Понимает два формата на входе:
- **сырой экспорт Telegram** (`result.json`) — `{"messages":[{"type","from","text"}, ...]}`
- **список сессий** — `[{"messages":[{"role","content"}, ...]}]`

Пары «вопрос → ответ» строятся **по смене автора** (неперекрывающиеся); для одиночных
диалогов — `user → assistant`. Служебные сообщения и `/команды` пропускаются.

Пишет три файла (с префиксом `--out`, по умолчанию `dataset`):
- `<out>_sharegpt.json` — ShareGPT
- `<out>_llama.txt` — ChatML (LLaMA)
- `<out>_lisp.lisp` — память Марка: `(("вопрос" "ответ" nil 1.0) ...)` — готово к загрузке
